# Onboarding checklist

Given a repo or team context, outline:

- **Day 0** — clone, build, test command, required tools, env files.
- **Day 1** — where docs live, how to run the app or CLI, who to ask.
- **Ongoing** — review process, branching, release cadence.

Tailor steps to the stack mentioned (language, package manager, CI). Mark unknowns explicitly instead of guessing.
