# Documentation style pass

When editing or reviewing docs:

- Use **clear headings** (`#` → `###`); one idea per section.
- **Code blocks** — language tags on fences; avoid screenshots for copy-pasteable content.
- **Links** — prefer stable URLs; describe what the reader gets when they click.
- **Tone** — direct, second person where appropriate; define acronyms on first use.
- **Accuracy** — flag commands or paths that look outdated.

Suggest concrete edits, not generic praise.
