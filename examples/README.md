# Example skill packs

English-only example **source packs** for the getskillpack ecosystem. Each subdirectory is a minimal skill you can bundle with `tar` and upload using `skillget publish` (see [Publish your own skill](../docs/PUBLISH_YOUR_SKILL.md)).

| Pack | Summary |
|------|---------|
| [commit-message-helper](commit-message-helper/) | Conventional commits and clear subject lines. |
| [pr-description-draft](pr-description-draft/) | PR title, summary, test plan, and rollout notes. |
| [security-review-pass](security-review-pass/) | Quick security checklist on changes. |
| [onboarding-checklist](onboarding-checklist/) | Repo and team onboarding steps. |
| [docs-style-pass](docs-style-pass/) | Documentation clarity and structure pass. |

These are **not** automatically published to the public registry; they are templates for docs and local testing.
