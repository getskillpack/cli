Как это работает

Цепочка от реестра до каталога в вашем репозитории.

Registry HTTP API и метаданные skills
→
skillget (CLI) search, install, config
→
skills.lock закреплённые версии
→
.skillget/ локальный каталог установки

Быстрый старт

Цель: за ~5 минут собрать бинарь и поставить первый skill. Реестр по умолчанию: https://registry.skpkg.org/api/v1 (можно переопределить).

# Сборка Go-клиента (рекомендуемый путь)
git clone https://github.com/getskillpack/cli.git && cd cli
go build -o skillget ./cmd/skillget

# Локальный или кастомный registry
export SKILLGET_REGISTRY_URL=http://localhost:3000/api/v1

./skillget search
./skillget install <имя-skill>

После install CLI обновляет skills.lock и кладёт артефакты в .skillget/skills/<name>/<version>/.
